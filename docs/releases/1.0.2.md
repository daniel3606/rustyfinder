The first release built and published by the release workflow, with a DMG
installer and a Homebrew cask. The app works as in 1.0.1; only its version
and the README it shows as Help changed.

### Added

- **DMG installer**: open it and drag RustyFinder to Applications.
- **Homebrew**: `brew install --cask daniel3606/tap/rustyfinder`, with
  `brew upgrade --cask rustyfinder` for later releases.
- `SHA256SUMS.txt` with the checksums of the DMG and the ZIP.
